# Product Overview

個人の学習を目的としたプロジェクトタスク管理システム。仕様駆動開発・CI/CD・AWSを実践的に学ぶための題材であり、将来的には開発者自身が管理するチームのタスク管理ツールとしての実運用も視野に入れている。

## Core Capabilities

- タスクの作成・一覧表示・完了操作
- プロジェクト単位でのタスクのグルーピング
- タスクへの期限・担当者の設定
- （今後、要件定義フェーズで詳細化）

## Target Use Cases

- 開発者自身による個人学習用途（まずはここから）
- 将来的な社内チームでのタスク・スケジュール管理への転用

## Value Proposition

- 完成物としての価値だけでなく、以下の学習プロセス自体が目的
  - 仕様駆動開発（Kiro式 requirements → design → tasks）の実践
  - GitHub Actions を用いた CI/CD パイプラインの構築
  - AWS 上への段階的なデプロイ（S3/CloudFront・App Runner等 → RDS → ECS Fargate + IaC）
