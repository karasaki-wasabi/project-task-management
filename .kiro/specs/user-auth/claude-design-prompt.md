## プロンプト本文（ここからコピー）

```text
プロジェクト名の提案: user-auth（タスク管理 — 認証画面）

目的
社内向けタスク/案件管理アプリ「Task Delivery Management」に、公開自己登録とログインを追加する。見た目は既存アプリのデザインシステムを踏襲し、認証専用の別ブランドにしない。Google Stitch は使わない。モックは実装前の確定用。

参照する既存の視覚言語（厳守）
- ページ背景: slate-50 (#f8fafc)
- サーフェス: 白 (#ffffff)、枠は ring-1 ring-slate-200、角丸 rounded-lg (8px) / 入力・ボタンは rounded-md (6px)
- 影は使わない（フラット）
- 本文・見出し: system-ui 系 sans-serif、h1 は text-xl font-semibold tracking-tight
- アクセント青 (#2563eb / hover #1d4ed8) は主要操作ボタンとリンク・フォーカスのみ。状態色としての青多用は禁止
- Primary ボタン: bg-blue-600 text-white text-sm
- Secondary ボタン: 白背景 + border border-slate-300
- 入力: border-slate-300、focus で青リング
- エラー: 画面上部の赤系アラートボックス（ErrorAlert 相当）。フィールド横の赤文字だらけにしない
- side-stripe（左色線）禁止、ダークモードなし、display 書体なし、紫グラデやグラスモーフィズム禁止
- 既存ヘッダー: sticky、白背景、下線、左にアプリ名「Task Delivery Management」、右にナビリンク（選択中は bg-blue-50 text-blue-700）

作ってほしい画面（デスクトップ幅を主、モバイルも破綻しないこと）

1) 登録画面 `/register`
- 未ログイン専用。業務ナビは出さない（または最小）。アプリ名は残してよい
- 入力: メールアドレス、表示名、パスワード（8文字以上である旨の短いヘルプ可）
- 主要 CTA: 「登録」
- ログイン画面への導線（例: すでにアカウントがある方向け）
- 失敗時: 上部にエラーアラート枠（文言はプレースホルダで可）
- パスワードを画面上にエコー表示しない（通常の password 入力）

2) ログイン画面 `/login`
- 未ログイン専用。業務ナビは出さない（または最小）
- 入力: メールアドレス、パスワード
- 主要 CTA: 「ログイン」
- 登録画面への導線
- 失敗時: 上部エラーアラート（「メールアドレスまたはパスワードが正しくありません」程度の粒度。どれが違うか分ける表示はしない）

3) ログイン後のヘッダー（既存レイアウトの差分）
- 既存の sticky ヘッダーをベースに、ログイン済みであることが分かる要素を追加
  - 表示名の提示
  - 「ログアウト」操作（Secondary またはテキストリンク相当。破壊的に見せすぎない）
- 既存ナビ（ダッシュボード/タスク/カンバン等）は維持する想定でよい
- 旧「ユーザー」ナビで名前だけ登録していた画面は、本スペックで名前登録・削除をやめる。モックでは次のいずれか一方を示すこと（両方の案を出して比較してよい）
  A. ナビから「ユーザー」を外し、担当者候補は各画面の既存セレクトのまま
  B. 「ユーザー」は一覧のみ（表示名・メールの読み取り専用リスト）。登録・削除ボタンなし

4) 未ログインで業務 URL に来たときの扱い（1枚でよい）
- 業務内容は見せず、ログインへ誘導する状態
- 全面ブロッキングの派手な壁ではなく、既存トーンのシンプルな誘導（ログインへの CTA + 登録へのリンク）

情報設計の制約（要件準拠）
- ロールや権限の違いを示す UI は作らない（ログイン済みは対等）
- ワークスペース切替・招待・プロフィール編集・パスワード再設定・ソーシャルログインは出さない
- 「名前だけ入力してユーザー登録」する旧 UI は出さない

出力してほしいもの
- 上記 1〜4 の画面モック（必要なら A/B のユーザー一覧方針を並べた比較）
- 各画面の主要コントロール一覧（ラベル文言つき）
- 採用推奨案を1つ明示（特にヘッダーのログアウト配置と、旧ユーザー画面の扱い A or B）
- デスクトップを主とし、狭い幅での崩れ方の注意があれば短く記す

トーン
Operate モードの実用ツール。装飾より走査性。認証画面だけランディングページ風にしない。ヒーロー画像・統計・余計なマーケティング文は不要。
```
