## プロンプト本文(ここからコピー)

```text
プロジェクト名の提案: error-page(タスク管理 — 共通エラーページ)

目的
社内向けタスク/案件管理アプリ「Task Delivery Management」に、Nuxtの共通エラーページ
(error.vue)を新設する。現在このファイルは存在せず、404/403/401/500などの致命的エラー発生時に
Nuxtの素のデフォルト表示が出てしまっている。見た目は既存アプリのデザインシステムを厳密に踏襲する。
Google Stitch は使わない。モックは実装前の確定用。

参照する既存の視覚言語(厳守。既存画面と地続きに見えること)
- ページ背景: bg-slate-50
- カード/サーフェス: bg-white
- 枠線: カード border-slate-200 / フォーム入力 border-slate-300 / 薄い区切り線 border-slate-100
- 角丸: カード・入力は rounded-md、モーダルパネルやドロップダウンは rounded-lg、バッジは rounded-full
- 影は控えめに使用: カード shadow-sm(hover で shadow-md)。重いドロップシャドウやグロー、
  グラスモーフィズムは禁止
- フォント: Noto Sans JP(見出し・本文とも同一ファミリー)。見出しは font-semibold
- アクセント: primary-600 (#1d4ed8) を主要操作ボタンに、hover は primary-700 (#1e40af)。
  フォーカスリングは focus:ring-2 ring-primary-500
- Primary ボタン: rounded-md bg-primary-600 px-3 py-2.5 text-sm font-medium text-white
  hover:bg-primary-700
- Secondary ボタン: rounded-md border border-slate-300 bg-white px-3 py-2.5 text-sm
  font-medium text-slate-700 hover:bg-slate-50
- アイコン: インラインSVGのみ(アイコンライブラリは新規導入しない)。heroicons-outline相当の
  スタイル(viewBox 0 0 24 24、fill none、stroke currentColor、stroke-width 2)を踏襲する
- ダークモードなし、side-stripe(左色線)禁止、紫グラデーション禁止、イラスト調のカラフルな
  マスコット画像は使わない(実用ツールのトーンに合わない)

参考: 既存のログイン画面(pages/login.vue)は左に暗色(bg-slate-900)のブランドパネル、
右に白背景の中央寄せコンテンツという2カラム構成で、アプリ共通のヘッダー/ナビは持たない
独立レイアウトになっている。

作ってほしい画面(デスクトップ幅を主、モバイルも破綻しないこと)

1) レイアウト比較(最優先で決めたい論点)
   エラーページに、通常画面と同じヘッダー(ロゴ・ナビ・ワークスペース切替・ログアウト)を
   残すか、login.vueのような完全に独立したレイアウト(ヘッダーなし、中央寄せの1カラム)に
   するかを2案で比較してほしい。
   A案: 通常画面のヘッダーを残し、その下の本文エリアだけがエラー表示になる
   B案: ヘッダーなし、画面全体を使った中央寄せのエラー表示(login.vue に近い構成)
   どちらもメッセージ・アイコン・ボタン配置は同じでよいので、ヘッダーの有無による
   印象の違いが比較できる形にしてほしい。

2) 404 Not Found
   「お探しのページが見つかりません」旨のメッセージ。アイコンまたは簡潔な図形表現。
   「ホームへ戻る」ボタンのみ。

3) 403 Forbidden
   「このページへのアクセス権限がありません」旨のメッセージ。
   「ホームへ戻る」ボタンのみ。404とアイコン/表現を変えて区別できるようにしてほしい。

4) 401 Unauthorized
   「ログインが必要です」旨のメッセージ。
   「ホームへ戻る」ボタン(Secondary)と「ログイン画面へ」ボタン(Primary)の2つを表示。
   どちらを主操作として強調するかも含めて提案してほしい。

5) 500 予期せぬエラー
   「予期せぬエラーが発生しました」旨のメッセージ。原因の詳細は出さない
   (スタックトレース等の技術的情報は表示しない)。
   「ホームへ戻る」ボタンのみ。

6) 汎用フォールバック(404/403/401/500以外のステータスコード用)
   4xx用と5xx用をそれぞれ1画面ずつ。「エラーが発生しました(ステータスコード: {code})」のように
   コード自体は表示しつつ、専用メッセージほど詳しくない一般的な文言にする。
   「ホームへ戻る」ボタンのみ。

情報設計の制約(要件準拠)
- 表示するのは上記6状態(404/403/401/500/汎用4xx/汎用5xx)のみ。エラーコード一覧のような
  網羅的な設計図は不要
- エラーメッセージにユーザーの権限詳細やサーバー内部情報を含めない(一般的な文言に留める)
- 「戻る」ボタンは常にアプリのトップページへの遷移(ブラウザの戻る操作ではない)

出力してほしいもの
- 上記1〜6の画面モック(1はA/B比較を含む)
- 各画面の主要コントロール一覧(ラベル文言つき)
- 採用推奨案を1つ明示(特にレイアウトのA/B、401でのボタンの強弱)
- デスクトップを主とし、狭い幅での崩れ方の注意があれば短く記す

トーン
Operate モードの実用ツール。装飾より明快さ。ユーザーが次に何をすればよいかが
一目で分かることを優先する。
```

## プロンプト本文(ここからコピー)

```text
前回のモック(レイアウトA/B比較、404/403/401/500/汎用4xx/汎用5xxの6状態)のレビュー結果です。
以下を反映してください。

1. レイアウトはB案(ヘッダーなし・全画面中央寄せ)を採用として確定します。以後の全画面をB案の
   構成で統一してください。A案(共通ヘッダーを残す)は不要です。

2. 各状態で「意味を表す円アイコン」と「生のステータスコード(404などの数字バッジ)」が
   別々の要素として縦に並んでいるのを、1つの視覚ユニットに統合してください。現状は
   アイコンの意味(絵)と数字(技術的な符丁)が接続されずに積まれているだけに見えます。
   次の2案を作って比較してほしい(6状態すべてに適用した場合の見え方で比較すること)。

   統合案1: バッジ重ね方式
   56pxの円アイコンの右下(または下端)に、ステータスコードの小さなピル(バッジ)を
   一部重ねて配置する。通知カウンターのように、アイコンとコードが1つの複合アイコンとして
   目に入る構成。

   統合案2: コード主役方式
   独立した数字バッジを廃止し、同じ56pxの円の中にステータスコード自体を主要な文字として
   描き(例: 円の中央にコードの数字、意味を表すアイコンは円の外周に沿った小さなモチーフや
   円の背景パターンとして控えめに添える程度)、1つの円が「意味+コード」を兼ねる構成。

   汎用フォールバック(4xx/5xx)ではコード自体が状態の主要な識別情報になるため、
   採用した統合方式がそちらでも違和感なく機能するかも確認してほしい。
   比較の上、推奨案を1つ明示してください。

3. 403のメッセージ文言を修正してください。現在の「アクセスが必要な場合は、
   ワークスペースの管理者にお問い合わせください」は、このプロダクトにまだ「管理者」という
   ロール自体が存在しない(RBACは未実装、後続仕様)ため、実在しない役割への問い合わせを
   促す誤解を招く文言です。「管理者」という語を使わず、権限が必要な旨と、心当たりがない
   場合の一般的な確認を促す文言に直してください(特定のロール名は出さない)。

出力してほしいもの
- 上記1〜3を反映した更新版(B案に統一した6状態、アイコン/コード統合案1・2の比較、
  修正済みの403メッセージ)
- 変更点の要約
```

## プロンプト本文(ここからコピー)

```text
アイコン/コード統合は統合案1(バッジ重ね方式)を採用として確定します。統合案2(コード主役方式)
は不要なので、以後の全画面を統合案1ベースにしてください。残る指摘は2点です。

1. 汎用フォールバック(4xx/5xx)の2状態だけ、コードバッジをより目立たせてください。
   404/403/401/500の4状態はメッセージ本文だけで意味が伝わるためバッジは現状の小さな

   - バッジのフォントサイズ・パディングを他の4状態より一回り大きくする、または
   - バッジの背景色をアイコン円と同じ濃さにして、円全体がバッジのように見える構成にする
   どちらが既存の視覚言語(primary-600系のアクセント、slate系の中立トーン)と馴染むか
   判断した上で、汎用4xx/5xxの2画面を更新してください。404/403/401/500の4画面は
   現状のバッジサイズのまま変更不要です。

2. 500のメッセージから「解決しない場合はシステム担当までご連絡ください。」の一文を削除して
   ください。このプロダクトには個人開発・少人数チーム利用の想定しかなく、正式な問い合わせ窓口が
   存在しないため、実在しない連絡先を案内する文言になっています。「時間をおいて再度お試しください。」
   のみに短縮してください。

出力してほしいもの
- 汎用フォールバック(4xx/5xx)のバッジを目立たせた更新版
- 500のメッセージを短縮した更新版
- 変更点の要約
```
